# Banned Output Patterns

These patterns must never appear in output. Every skill and command that produces text a person reads references this file, alongside `_shared/wording-standard.md`.

## Punctuation

- No em dashes (—). Replace with a comma, new sentence, or parentheses.
- No ellipses (...) for stylistic effect.
- No exclamation marks unless in the original input.
- No overuse of semicolons in casual or neutral writing.

## Vocabulary — never use

delve, underscore, pivotal, realm, harness, illuminate, facilitate, refine, bolster, differentiate, streamline, enhance, empower, foster, navigate (metaphorical), insight, insights, landscape, nuance, nuances, intricate, tapestry, camaraderie, palpable, grapple, vibrant, solace, amidst, fleeting, unravel, cacophony, ignite, prioritize, robust, transformative, revolutionize, innovative, cutting-edge, game-changing, seamless, scalable, profound, versatile, meaningful, imperative, dynamic, impactful, optimize, elevate, enable, leverage, synergy, ecosystem, framework, paradigm, holistic, actionable

**Names are exempt.** A banned word is banned as filler, not as a name. When a word is the actual name of the thing you are talking about, use it: the *harness* that runs agents and worktrees, the *ecosystem* file listing installed tools, a *framework* the project actually depends on, backlog *refinement*, story *prioritisation*. The ban is on reaching for the word when a plain one would do.

## Phrases — never use

- "That being said" / "It's worth noting" / "It's important to note"
- "This means that..." / "This highlights..." / "This underscores..."
- "In other words," / "Put simply," / "To put it differently,"
- "Overall," / "In summary," / "In conclusion,"
- "When it comes to" / "At its core" / "In many ways"
- "Provides valuable insights" / "Highlights the importance of"
- "Paving the way" / "Sheds light on"
- "From a broader perspective" / "In a broader sense"
- "Generally speaking" / "Broadly speaking"
- "To some extent" / "Arguably"
- "Tends to" / "Typically"
- "A key takeaway is"
- "One of the most important" without specificity
- "As a result" used repeatedly in adjacent sentences

## Opening affirmations — never use

- "Certainly," / "Absolutely," / "Of course," / "Sure,"
- "Great question," / "Good question,"
- "I hope this message finds you well"
- "Just wanted to reach out"
- "Happy to help" / "I'd be happy to help"
- "Thanks for your question"

## Structural patterns — never produce

- Tidy closing sentences that restate the paragraph without adding value
- Balanced argument framing when not required
- Generic abstraction instead of concrete specifics
- Hedging clusters within the same sentence
- Abstract nominal closers: "which is the wrong semantic", "which is the correct approach", "which addresses the root cause"
- Packed causal chains in a single sentence: "X does Y, which triggers Z, so you'd get W". Break into sequential short sentences or bullets.
- "Not only X, but also Y" escalation frames
- "It's not X, it's Y" contrasting frames

## Closing patterns — never use

- "Feel free to reach out"
- "Hope this helps"
- "Let me know if you have any questions"
- "Please don't hesitate to contact me"
- "Moving forward" used as a closing
- Forward-looking motivational statements not present in input
- Generic summaries that restate prior content without adding new information

## Grammatical and stylistic patterns — avoid

- Overly formal, impersonal tone when context does not require it
- Consistent sentence length and rhythm across paragraphs
- Excessive use of subordinate clauses
- Frequent nominalization instead of direct verbs
- Overuse of present participle clauses
- Repeated sentence templates with minor variation
- Dense information packing without variation in pacing
- Uniform paragraph structure across an entire response
