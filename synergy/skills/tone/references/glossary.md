# Tone glossary

Use these spellings for a clear project reference or dictation near-miss. Context must identify the intended term. These entries do not turn ordinary words into project names, expand every abbreviation or authorise changes to literal code and quotations.

## Project terms

- **System Mode**: a named system feature. Possible dictation errors include "system merge" and "system something".
- **System Level**: a named system concept. A possible dictation error is "simple system level".
- **Vantage Point**: the product name. **VP** is an acceptable short form; preserve it when used.
- **VP Bootstrap**
- **Reference Scripts**
- **User Story** and **User Stories**
- **Work Items**
- **Snapshot Builder**
- **DataFeed Scripts**: possible variants include "data feed scripts" and "datafeed scripts".
- **Snapshot Scripts**

## Existing sign-offs

When the source includes Adrienne's usual sign-off, preserve it:

